# Initial Baseline

## Goal Description
Document the existing features of PolyMetrics v1.2.1 to establish a baseline for future development. This covers the current codebase found in `src/`.

## Proposed Changes
This is a baseline documentation change. No code changes are proposed. The following features are currently implemented:
1.  **Revenue & Analytics**: Calculation of revenue, profit, Envato fees (tiered), buyer fees, and taxes on item pages.
2.  **UI Enhancements**: Integrated toolbar on item pages, charts (Revenue Breakdown, Distribution), and scroll-to-top/bottom/recommended controls.
3.  **Bookmark Manager**: Local storage-based bookmarking system with categories and valid item URL normalization.
4.  **Community Features**: Follow User buttons, Copy Comment content, Copy User HTML as Markdown.
5.  **Settings**: Management of Tax rate, Currency (with exchange rates), and toggle states.
